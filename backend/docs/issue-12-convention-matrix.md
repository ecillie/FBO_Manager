# Issue 12 API convention matrix

This is the completion-evidence matrix for [issue #12](https://github.com/ecillie/FBO_Manager/issues/12). The controlling requirements remain [ADR 0003](../../docs/architecture/decisions/0003-api-contracts-and-operational-data-flows.md) and [API contracts and operational data flows](../../docs/architecture/api-contracts-and-data-flows.md).

| Documented requirement | Shared implementation | Automated evidence |
| --- | --- | --- |
| Visible `/api/v1`, lowercase kebab-case resources, JSON/UTF-8, lower-camel properties, exact enum values | `ApiConstants`, controller mappings, strict Jackson settings, DTO enum validators | `ApiConventionHttpIntegrationTests.keepsEveryApplicationControllerRouteBelowTheVisibleMajorVersion`, `returnsBoundedCollectionEnvelopeWithStableSortRequestIdAndSecurityHeaders`, `rejectsUnknownJsonPropertiesOversizedBodiesRoutesVersionsAndMediaTypes` |
| Transport DTOs are separate from domain/JPA types; required, enum, generated-ID, code-format, quantity, and UTC timestamp validation precedes service calls | `ConventionReferenceRequest`, validation annotations in `platform.api.validation`, explicit request-to-command mapping | `ApiConventionHttpIntegrationTests.validatesRequestDtoAndIdempotencyHeaderBeforeTheApplicationServiceRuns`, `returnsValidEchoUsingTransportTypesAfterValidation` |
| Success `data`/`meta` envelopes; generated `BIGINT` and `NUMERIC(14,3)` values are strings; instants are UTC | `ApiResponse`, `ApiCollectionResponse`, `GeneratedId`, `FixedPrecisionQuantity`, `ApiResponseFactory` | `ApiWireTypesTests`, `ApiConventionHttpIntegrationTests.returnsBoundedCollectionEnvelopeWithStableSortRequestIdAndSecurityHeaders` |
| Stable safe errors for 400/401/403/404/409/413/422/429/500/503 with request ID, timestamp, retryability, and optional safe fields/details | `ApiExceptionHandler`, `ApiException`, error DTOs | `ApiConventionHttpIntegrationTests.returnsStableSafeEnvelopeForEveryDocumentedErrorFamily`, `rejectsUnknownJsonPropertiesOversizedBodiesRoutesVersionsAndMediaTypes` |
| PostgreSQL unique, foreign-key, check, deadlock, serialization, lock, timeout, and availability failures are classified without driver leakage | `DatabaseFailureClassifier` using SQLSTATE and an allowlist of migration constraint names | `DatabaseFailureClassifierTests` |
| Every ordinary collection is bounded to page size 1–100, rejects unknown parameters, allowlists filters/sorts, and appends a stable tie-breaker; raw Spring Data `Page` is forbidden | `@BoundedPage`, `ApiPageRequestArgumentResolver`, `ApiEnvelopeAdvice` | `ApiConventionHttpIntegrationTests.rejectsUnboundedUnknownAndUnsupportedCollectionQueries`, `returnsBoundedCollectionEnvelopeWithStableSortRequestIdAndSecurityHeaders`, `ApiEnvelopeAdviceTests` |
| Request IDs, structured safe access logs, body limits, exact credentialed origin, security headers, and untrusted forwarding defaults | `RequestCorrelationFilter`, `RequestBodySizeFilter`, `ExactOriginCorsFilter`, `ApiSecurityHeadersFilter`, `server.forward-headers-strategy=none` | `RequestCorrelationFilterTests`, `ApiConventionHttpIntegrationTests.replacesAnInvalidInboundRequestIdAndUsesTheAuthoritativeValueInTheEnvelope`, `permitsOnlyTheConfiguredExactCredentialedCorsOrigin`, `rejectsUnknownJsonPropertiesOversizedBodiesRoutesVersionsAndMediaTypes` |
| `Idempotency-Key` syntax and per-operation opt-in are shared while replay persistence remains in feature services | `@IdempotentOperation`, `IdempotencyKey`, `IdempotencyKeyArgumentResolver` | `ApiConventionHttpIntegrationTests.rejectsMissingOrMalformedIdempotencyKeys`, `returnsValidEchoUsingTransportTypesAfterValidation` |
| A reference route demonstrates the conventions without returning a persistence record | `GET` and `POST /api/v1/platform-conventions`; the side-effect-free reference service maps command/result types to HTTP DTOs | `ApiConventionHttpIntegrationTests` |

The reference route is contract scaffolding, not a business or database resource. Feature controllers reuse `platform::api` types and annotations, map their own HTTP DTOs to application commands, and leave persistent replay semantics to the application transaction and `idempotency_records` foundation.
